Welcome to Aether RAG

This application represents a strict **Model Context Protocol (MCP)** execution pipeline. Upload your documents in the left sidebar, and search them here.

How does it work?

  • • You submit a question.
  • • FastAPI starts an external **MCP subprocess** using `sys.executable`.
  • • MCP queries Chroma DB, performs embedding math, and retrieves relevant chunks.
  • • MCP returns structured JSON context to the backend.
  • • OpenAI completes your question **strictly grounded** in that context.
